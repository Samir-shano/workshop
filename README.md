5. Rövarspråköversättare
Kontext: Textomvandling, allt sker på text som skrivs in direkt i konsolen.

Som användare vill jag skriva in text direkt och få den omvandlad till rövarspråket.
Som användare vill jag kunna omvandla tillbaka från rövarspråket till vanlig text.
Som användare vill jag kunna kryptera min text med en enkel algoritm (t.ex. Caesar-chiffer) och dekryptera den igen.
Som användare vill jag mata in punktlistor (bullet points) och få dem sammanställda till ett sammanhängande e-postmeddelande.
Som användare vill jag kunna göra det omvända: klistra in ett längre textstycke och få det komprimerat till punktlistor.
(Stretch) Som användare vill jag kunna läsa in och skriva ut till fil istället för att skriva in text manuellt.
